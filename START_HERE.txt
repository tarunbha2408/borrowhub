--------------------------------------------------------------------------------

whether MySQL connects, whether the seed accounts and password hashes are correct, and
what /api/auth/login answers. Every FAIL comes with the exact fix.

2a. EASIEST: SET UP THE WHOLE DATABASE WITH ONE COMMAND (Linux)
--------------------------------------------------------------------------------
  bash database/setup_database.sh

It loads schema.sql + seed.sql, creates the application database user and verifies the
result. (Back up any existing data first - schema.sql drops the borrowhub database.)

2b. IF THE DATABASE DOES NOT CONNECT (error 1698 / 1045)
--------------------------------------------------------------------------------
On Arch/Fedora the MariaDB root account often uses 'unix_socket' authentication, so it
does not accept a password. Create a dedicated user for the application:

  sudo mariadb < database/create_app_user.sql

Then set this in backend/.env:
  DATABASE_URL=mysql+pymysql://borrowhub:BorrowHub2026@localhost:3306/borrowhub?charset=utf8mb4

and restart the server. Details: docs/TROUBLESHOOTING.md (Fix 2b)

4. REAL EMAIL DISPATCH (SENDING LIVE OTPS TO INBOXES)
--------------------------------------------------------------------------------
By default, BorrowHub logs the OTP code directly to the server terminal and
auto-fills it into the web form for instant testing.

To send real OTP emails directly to student Gmail / SVNIT inboxes:
1. Open backend/.env
2. Configure your SMTP provider (Gmail, Outlook, or SVNIT SMTP):
     SMTP_HOST=smtp.gmail.com
     SMTP_PORT=587
     SMTP_USER=your_email@gmail.com
     SMTP_PASSWORD=your_16_digit_app_password
     SMTP_FROM_EMAIL=your_email@gmail.com
     SMTP_FROM_NAME="BorrowHub SVNIT"
     SMTP_TLS=True

How to get a Gmail App Password:
  - Visit: https://myaccount.google.com/security
  - Enable "2-Step Verification" (if not already enabled)
  - Search for "App Passwords" -> Type name "BorrowHub" -> Click Generate.
  - Paste the 16-character password into SMTP_PASSWORD.
